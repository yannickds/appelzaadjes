# Whale Walk

In collaboration with <a href="https://osta.be/" target="_blank" rel="noopener noreferrer">OSTA: Organization for the Spiritual Treatment of Animals</a>

Since humans began hunting whales, their population has fallen from four or five million to approximately 1.3 million. It does not have to be this way. On the beach, between low and high tide, we bring a whale back to life. As the tide comes in, the sea will take the whale back. Repeat this process several million times and the whale population will be restored. Simple, right?

Together, walking attentively, we create a large drawing of a whale on the beach, measuring 30 by 50 metres. Ninety-nine signs are numbered from 1 to 99. Participants walk from 1 to 2 to 3 to … 98 to 99, tracing every line of the drawing along the way.

## Why?

When we approach the climate as a problem, it also seems to have a solution. According to the conventional reductionist narrative, that solution is to measure and regulate CO₂ molecules: counting CO₂, in other words. The climate, however, is extraordinarily complex—a <a href="https://andnowwhat.be/about/glossary/" target="_blank" rel="noopener noreferrer">wicked problem</a>. It calls for a <a href="https://charleseisenstein.org/essays/initiation-into-a-living-planet/" target="_blank" rel="noopener noreferrer">multifaceted and profound approach</a>. To make this point playfully, we propose counting whales instead of CO₂ from now on, increasing the whale population as we walk.

It is uncertain whether whales will survive the current mass extinction. If they are given the chance, perhaps one day they will return to land, <a href="https://dark-mountain.net/will-the-whales-inherit-the-earth/" target="_blank" rel="noopener noreferrer">evolving into a new intelligent species</a> that morally surpasses humanity. To keep this potential future open, humanity must radically change course.

<script>
  (() => {
    const carousel = document.querySelector(".walvis-carousel");

    if (!carousel) return;

    const slides = carousel.querySelectorAll(".walvis-slide");
    const dots = carousel.querySelectorAll(".walvis-dots button");
    const counter = carousel.querySelector(".walvis-counter");
    const previousButton = carousel.querySelector(".walvis-previous");
    const nextButton = carousel.querySelector(".walvis-next");

    let currentSlide = 0;

    function showSlide(index) {
      currentSlide = (index + slides.length) % slides.length;

      slides.forEach((slide, slideIndex) => {
        slide.classList.toggle(
          "is-active",
          slideIndex === currentSlide
        );
      });

      dots.forEach((dot, dotIndex) => {
        const isCurrent = dotIndex === currentSlide;

        dot.classList.toggle("is-active", isCurrent);
        dot.setAttribute(
          "aria-current",
          isCurrent ? "true" : "false"
        );
      });

      counter.textContent =
        `${currentSlide + 1} / ${slides.length}`;
    }

    previousButton.addEventListener("click", () => {
      showSlide(currentSlide - 1);
    });

    nextButton.addEventListener("click", () => {
      showSlide(currentSlide + 1);
    });

    dots.forEach((dot, index) => {
      dot.addEventListener("click", () => {
        showSlide(index);
      });
    });

    carousel.addEventListener("keydown", event => {
      if (event.key === "ArrowLeft") {
        showSlide(currentSlide - 1);
      }

      if (event.key === "ArrowRight") {
        showSlide(currentSlide + 1);
      }
    });

    showSlide(0);
  })();
</script>
